## 决策总表（D1–D13）

| 编号 | 主题 | 正式锁定规则 | 规格依据 |
|---|---|---|---|
| **D1** | 技能动作 ID 命名 | `Core_`、`Combat_`、`Presentation_` 类 Blender Action 转动画 ID 时去掉类别前缀并小写（如 `Core_Idle -> idle`）；**`Skill_` 类动作保留 `skill_` 前缀**（`skill_01`、`skill_02`、`skill_03`、`skill_ultimate`，专属技能动作亦同，如 `Skill_Moon_Slash -> skill_moon_slash`）。`part1` §8 目录示意图中的 `ultimate/` 视为简写，不采用。 | `part1` §7 命名表、§9.3 `SkillDefinition` |
| **D2** | 核心动作「已实现」判定 | 核心动作清单（25 项）中，未列入 `unsupported_core_moves` 的项必须存在 `metadata/<id>.json`；攻击类（`light_01`、`light_02`、`medium_01`、`heavy_01`、`air_attack`、`throw`）与技能类（`skill_01`..`skill_ultimate`）还**必须**存在 `framedata/<id>.json`；`dash` 与 `wakeup` **允许可选**提供 `framedata/dash.json`、`framedata/wakeup.json`（配置冲刺取消或起身无敌帧时使用）。 | `part1` §7、§9.2、§9.5；`part3` §4 |
| **D3** | FrameData 帧起点与闭区间 | 所有模拟帧编号从 **`0`** 开始；招式总长 `total = startup + active + recovery`（有效 tick 为 `0 .. total - 1`）。所有 `[start, end]` 帧区间均为**闭区间（含首尾，`start <= tick <= end`）**：当 `startup > 0` 时前摇为 `[0, startup - 1]`；当 `active > 0` 时有效窗口为 `[startup, startup + active - 1]`；阶段值为 `0` 表示该阶段占 0 帧。 | `part1` §7、§9.3 `light_01.json` |
| **D4** | 矩形坐标系、朝向镜像与物理符号 | ① 矩形 `[x, y, w, h]` 均为整数（`1px = 1000` 单位，`w > 0, h > 0`），原点 `(0, 0)` 位于角色脚底地面锚点，`+Y` 向下（地面 `y = 0`，空中 `y < 0`）。<br>② **朝向镜像公式**：面向右（`facing = +1`）时世界矩形为 `[pos_x + x, pos_y + y, w, h]`；面向左（`facing = -1`）时世界矩形为 **`[pos_x - x - w, pos_y + y, w, h]`**。<br>③ **整数 AABB 相交采用严格不等号 `<`**：`a.x < b.x + b.w and b.x < a.x + a.w and a.y < b.y + b.h and b.y < a.y + a.h`（边缘贴合不算相交，防止挤压盒抖动）。<br>④ **纵向符号**：`stats.jump_velocity > 0` 与 `stats.gravity > 0` 存正标量（起跳赋 `vel_y = -jump_velocity`，空中每帧 `vel_y += gravity`）；`knockback: [kx, ky]` 为带符号向量，`kx > 0` 沿攻方朝向推开，**`ky < 0` 表示向上击飞浮空**。 | `part1` §9.3；`part3` §2、§3、§5 |
| **D5** | `hitstop` 必填与停顿扩展 | 每个 `hitboxes[]` 条目及 `projectile_spawn[].hit` 对象**必须**显式填写 `hitstop`（整数 `>= 0`，`part1` §9.3 视为节选示例）；同时支持可选整数字段 **`block_hitstop`**（`>= 0`，省略时运行时默认等于 `hitstop`）。`FrameData` 顶层预留可选对象 **`super_freeze`**（`{"frame": int, "duration": int}`，必杀技定格帧）。 | `part3` §8 |
| **D6** | 身体碰撞盒（pushbox）与全局战斗配置 | ① 身体碰撞盒写在 `framedata/hurtboxes.json` 的 `<配置名>.pushbox` 下，且**必须覆盖全部 4 个姿态：`stand`、`crouch`、`air`、`down`**（保留 `pushbox.down` 防止对手站进倒地角色原点导致起身朝向翻转抖动）。<br>② 跨 IP 全局战斗规则（场地半宽边界、角落反推千分比、输入缓冲帧数、指令识别窗口、连招伤害递减表、浮空上限、同招式连段上限）统一存放在非 IP 配置文件 **`combat/combat_config.json`**（Phase 1 建立，存在时由 `validate.py` 校验）。 | `part1` §9.1；`part3` §3、§5、§6、§7 |
| **D7** | 投射物数据拆分与单向引用链 | `SkillDefinition` 统一通过 `move_id` 单向关联 `FrameData`，再由 `FrameData.animation_id` 关联动画元数据。`FrameData.projectile_spawn[]` 负责生成帧、本地偏移、判定矩形及命中伤害/硬直/停顿（`hit`）；`SkillDefinition.projectile` 负责表现特效路径、飞行速度与生命周期。 | `part1` §9.1–9.3；`part3` §5 |
| **D8** | 数值与职责唯一归属规则 | 通过字段归属表（`KEY_OWNERS` / `MULTI_KEY_OWNERS`）强制单点定义：<br>- **`framedata` 独占**：`damage`、`knockback`、`hitstun`、`blockstun`、`hitstop`、`block_hitstop`、`hitboxes`、`cancel_windows`、`invuln_frames`、`armor_frames`、`startup`、`active`、`recovery`、`projectile_spawn`、`hurtbox_override`、`combat_events`、`super_freeze`、`meter_gain_on_hit`、`meter_gain_on_block`、`meter_gain_on_whiff`。<br>- **`skill` 独占**：`cooldown`、`cost`、`projectile_gravity`。<br>- **`fighter` 独占**：`stats`、`max_hp`、`walk_speed`、`jump_velocity`、`defense`、`gravity`、`max_gauge`、`gauge_gain_on_hurt_pct`、`gauge_gain_on_block_pct`。<br>- **`animation_id` 限定**：仅允许出现在 `animation` 与 `framedata` 中，**严禁出现在 `skill` 或 `fighter` 中**。 | `part1` §9.2；`part3` §7 |
| **D9** | 测试内容包 `test_pack` 隔离 | 占位测试角色放在 `ip_content/test_pack/`，`ip.json` 标记 `"test_only": true`。运行时 `DataLoader` 默认过滤 `test_only == true` 的内容包（正式选角界面不可见，仅测试与开发调试显式加载）。 | `part1` §9.3；`part3` §13 Phase 1 |
| **D10** | `sources.json` 覆盖范围与通配限制 | ① 角色级检查 `blender/ model/ textures/ animations/ sprites/ previews/`；IP 级除检查 `stages/ effects/ audio/` 外，还检查 **`ip_content/<ip>/` 根目录下的非文档资产文件（如 `cover.png`）**。<br>② 当条目未标记 `"placeholder": true` 时，仅允许对管线派生目录（`animations/*`、`sprites/*`）使用通配符；对源资产目录（`blender/`、`model/`、`textures/`、`previews/`、`audio/`、`stages/`、`effects/`）使用 `*`/`?` 时输出 `SOURCES_BROAD_WILDCARD` 警告。 | `part1` §6、§9.5；`part2` §8 |
| **D11** | 核心代码禁止 IP 字符串（范围与分级防误报） | ① **扫描范围**：除排除目录（`ip_content/`、`tests/`、`asset_pipeline/`、`addons/`、`docs/`、`.venv/`、`.cache/`、`.git/`、`.godot/`、`build/`）及本机工具配置外，仓库内所有 `.gd`、`.tscn`、`.tres`、`.gdshader`、`.godot`、`.cfg`、`.json`、`.cs`、`.py`（含根目录 `project.godot` 及任意新增模块目录）以及 10 个核心模块目录内的 `.md` 全部纳入扫描。<br>② **三级精准匹配**：<br>  - **一级（无条件严禁）**：路径片段 `ip_content/<ip>` 与 `characters/<char>`、完整角色 ID `<ip>.<char>`（含单字母角色如 `arknights.w`）、IP `id` 与 IP `name_en`（长度 `>= 3` 词边界，短 ID 查引号字面量）、以及长度 `>= 2` 的非 ASCII 显示名（如 `明日方舟`、`阿米娅`、`霜星`）。<br>  - **二级（专属角色词严禁）**：不在引擎常用术语碰撞表（`ENGINE_COLLISION_WORDS`）中的长度 `>= 3` 角色目录名与 `name_en`（如 `amiya`、`ch_en`、`dummy_a`），按不区分大小写词边界严禁。<br>  - **三级（碰撞词与单字防误报）**：落入 `ENGINE_COLLISION_WORDS` 的通用英文词（如 `red`、`ash`、`frost`、`spot`、`light`、`heavy`、`block`、`dash`）及长度 `< 3` 的短英文名（如 `w`），放行裸标识符与注释（如 `Color.RED`、`var w`），但严禁引号内点号后缀（如 `".red"`、`".w"`）及一级规则中的完整 ID/路径；单字非 ASCII 显示名（如 `红`、`陈`、`空`）仅严禁引号内字符串字面量（如 `"红"`），放行 `# 攻击框（红）` 等普通中文注释。 | `part1` §2、§4、§9.5 |
| **D12** | 个人服务器范围与来源真实性 | 本项目仅部署于个人服务器，不对外传播、不商用；`sources.json` 照常强制维护，正式 IP 角色中凡未获公开再分发授权的资产，`"redistributable"` 必须如实填 `false`。 | `part1` §6；用户确认 |
| **D13** | 64 位整数除法语义 | GDScript 原生 `/` 为向零截断、`%` 与被除数同号。`core/` 定点数工具统一封装强类型 `div_trunc(a: int, b: int) -> int` 与 `div_floor(a: int, b: int) -> int`（基于 `posmod`）：**有符号模拟坐标转屏幕像素必须用 `div_floor(val, 1000)`**（保证跨过 `0` 点时每个像素桶严格等宽 `1000`），非负帧映射与百分比缩放走整数工具函数，禁止裸 `Variant` 除法。 | `part3` §2、§9；GUT 实测 |
